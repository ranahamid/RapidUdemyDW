# Support

## Getting Help

### Before Reporting an Issue

1. **Check the [README](README.md)** for setup instructions and troubleshooting tips.
2. **Update to the latest version** — your issue may already be fixed.
3. **Check existing issues** on the repository.

### Reporting a Bug

When reporting a bug, please include:

1. **Application version** (visible on the About page)
2. **Operating system** and version (e.g., Windows 11 23H2)
3. **Steps to reproduce** the issue
4. **Expected behavior** vs. **actual behavior**
5. **Error messages** (if any — from the app UI, not from log files)
6. **Screenshots** if applicable

⚠️ **Never include your access token, cookies, or any authentication credentials in bug reports.**

### Requesting a Feature

Feature requests are welcome! Please describe:
- What you'd like to see
- Why it would be useful
- Any alternatives you've considered

### Log Files

If asked for log files during troubleshooting:

1. Open the **About** page in the app
2. Note the **Log Directory** path
3. Zip the log files from that directory
4. **Review the logs first** — while the app redacts sensitive information, please double-check before sharing
